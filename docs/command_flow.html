⚙️ System Handlers & ISR Callbacks

Hardware Watchdog Handler

Runs at 1Hz. Expects heartbeat CSP packet from OBC every 1000ms. If missed, triggers mock MCU system reboot via `system_reset()`.

SPI/v-bus ISR Handler

In HW mode: STM32 DMA/SPI interrupt signals packet received. In SIM mode: `v_bus_receive()` blocks with timeout, then unblocks IPC Router task via queue notify.

CRC Validation Handler

Every CSP packet passes through `crc32_validate()`. On failure: packet is dropped, error counter incremented, LC notified if threshold exceeded.

📡 End-to-End Command Flow with Queues & Handlers

1

Ground Station → OBC (UDP)

Ground station transmits a CSP packet via UDP to the OBC. The packet contains a command with destination port 10 (ADCS).

2

OBC Command Ingest (CI) — CRC Validation Handler

CI thread receives the CSP packet, invokes `crc32_validate()`. If CRC passes, decodes the destination port and enqueues into the TTS priority queue (min-heap).

3

OBC Time-Tagged Scheduler (TTS) — Queue Handler

TTS 1Hz loop checks if the top command in the min-heap has matured (UTC timestamp <= system RTC). If mature, pops from heap and dispatches.

4

OBC → MCU via SPI (v-bus)

TTS dispatches the mature command. OBC builds a CSP packet (src=OBC, dst=ADCS port 10) with CRC-32 and sends it over SPI via v-bus.

5

MCU v-bus ISR Handler → IPC Router Task

SPI/v-bus ISR handler signals packet received. IPC Router task unblocks, parses CSP header, invokes `crc32_validate()` handler, looks up destination port in routing table, and routes payload to `adcs_command_queue`.

6

MCU ADCS Task — Queue Receive & Handler

ADCS task (50 Hz) blocks on `xQueueReceive(adcs_command_queue)`. When the IPC Router places the command on the queue, ADCS unblocks, applies the quaternion setpoint via PID handler, and computes reaction wheel outputs.

7

MCU → OBC via SPI (v-bus) — Telemetry Queue Handler

ADCS sends telemetry back through v-bus as a CSP packet (src=ADCS telemetry port 20, dst=OBC). The telemetry data is first placed on the `telemetry_queue` by the ADCS task, then the v-bus ISR handler transmits it.

8

OBC Telemetry Output (TO) → Ground Station (UDP)

OBC TO thread reads telemetry from the MCU queue, wraps it in a CSP downlink packet with CRC-32, and transmits via UDP to the ground station.
